# Hylme แอดมินรายวัน

เว็บสรุปแชทรายวันจากแท็ก Pancake ของ 4 เพจ Hylme ดูได้ที่ https://chinathiphylme-ctrl.github.io/hylme-admin/

## อัปโหลดไฟล์ทุกวัน

1. ใน Pancake export **สถิติแท็กแบบแยกเพจ** ของเมื่อวาน (ไม่ใช่แบบรวมทุกหน้า)
2. export **ไฟล์ข้อความ** ของเมื่อวาน ทุกเพจ
3. เปิดเว็บ → เมนู **อัปโหลดไฟล์** → ลากไฟล์ทั้งหมดมาวาง
4. ดูสรุปไฟล์ที่อ่านได้ ถ้ามีข้อความ "จะทับข้อมูลเดิม" แปลว่าวันนั้นเคยอัปโหลดแล้ว
5. ใส่รหัสอัปโหลด แล้วกด **บันทึก**

ไฟล์ข้อความถูกอ่านในเบราว์เซอร์ ชื่อลูกค้า เบอร์โทร และเนื้อหาข้อความจะถูกตัดทิ้งก่อนส่งขึ้นฐานข้อมูล

ถ้าเจอแท็กใหม่ที่ยังไม่จัดกลุ่ม ไปที่เมนู **จัดกลุ่มแท็ก** แล้วเลือกกลุ่ม (ต้องใช้รหัสเดียวกัน)

## เปลี่ยนรหัสอัปโหลด

เข้า Supabase → โปรเจกต์ `hylme-admin` → SQL Editor แล้วรัน (เปลี่ยน `รหัสใหม่`):

```sql
update settings set value = extensions.crypt('รหัสใหม่', extensions.gen_salt('bf', 10)) where key = 'upload_code';
```

ใช้รหัสยาวอย่างน้อย 10 ตัว ผสมตัวอักษรและตัวเลข ฐานข้อมูลเก็บเฉพาะ hash ของรหัส ไม่มีใครอ่านรหัสจริงได้ และใส่รหัสผิดแต่ละครั้งต้องรอ 1 วินาที

## ถ้าเว็บขึ้นว่าโหลดข้อมูลไม่ได้

Supabase แบบฟรีจะหยุดพักเองถ้าไม่มีใครใช้ 7 วัน ให้เจ้าของเข้า Supabase แล้วกด **Restore project**

## สำหรับนักพัฒนา

```bash
npm install
npm test          # ทดสอบ parse / grouping / metrics
npm run dev       # เปิดเว็บในเครื่อง (ใช้ .env.local)
npm run verify    # เทียบตัวเลขกับไฟล์ export จริงในโฟลเดอร์แม่ (ไม่ขึ้น git)
```

push เข้า `main` แล้ว GitHub Actions จะ build และขึ้น GitHub Pages ให้เอง โครงสร้างฐานข้อมูลอยู่ที่ `supabase/migrations/`
