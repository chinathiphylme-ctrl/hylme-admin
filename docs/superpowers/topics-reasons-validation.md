## ค้างภายนอกเครื่อง

เครื่องมือ Supabase `execute_sql` ตอบ `You do not have permission to perform this action` จึงยังไม่ได้อ่านนิยาม RPC ปัจจุบันหรือรัน migration บนฐานข้อมูลจริง ไฟล์ SQL อิงนิยามใน repository ต้องเทียบกับ live definition ก่อนรัน ยังไม่ได้ตรวจการบันทึกหัวข้อหรือเก็บประโยคแบบ end-to-end กับฐานข้อมูลจริง

ขั้นตอนถัดไป: เชื่อมต่อ Supabase ด้วยสิทธิ์เจ้าของโครงการ `dbxjssrswmggkfdlhslc` → ตรวจ schema/RPC → รัน migration → ตรวจอ่าน/เขียนโดยใช้ข้อมูลที่อนุมัติ → อัปไฟล์เก่าซ้ำตามที่ทีมเลือก → อนุมัติ merge/push เพื่อเผยแพร่ GitHub Pages
