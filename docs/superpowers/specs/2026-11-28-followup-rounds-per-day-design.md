# ติดตามรายวัน แยกรอบ 1–7 — Design (ฉบับสั้น)

วันที่ 28 พ.ย. 2026 · คำขอของพี่นุ่น ผ่านเจ้าของ

## Intent

แท็กใน Pancake มีแค่ถึง `ติดตาม4` ทีมอยากรู้ว่าแต่ละวันส่งการติดตามรอบไหนไปกี่ครั้ง รวมรอบ 5–7 ด้วย
ข้อมูลมีอยู่แล้ว: ทุก "บันทึกผล" ในแท็บติดตาม 7 รอบเป็นแถว `fu_events` (kind `round`, `round_no`, `at`)
แต่หน้ารายงานโชว์แค่ยอดรวมต่อแอดมิน

## Goals

- หน้ารายงาน (แท็บติดตาม 7 รอบ → รายงาน) มีการ์ดใหม่ "ติดตามรายวัน แยกรอบ"
  - แถว = วันในช่วงที่เลือก (ใหม่สุดก่อน) เฉพาะวันที่มีอย่างน้อย 1 ครั้ง
  - คอลัมน์ = รอบ 1 … รอบ 7 และ รวม · แถวสุดท้าย "รวมทั้งช่วง"
  - ใช้ตัวกรองเดิมของหน้ารายงานทั้งหมด (ช่วงวัน แอดมิน เพจ สินค้า) แอดมิน = ผู้ดูแลลูกค้า เหมือนตารางรายแอดมิน
  - วัน = วันที่กดบันทึก (เวลาไทย) เหมือน "ติดตามแล้ว (ครั้ง)" ตอนนี้
  - นับทุกครั้งที่เป็น kind `round` รวมรอบที่ระบบบันทึกจากแท็ก Pancake (เหมือนตารางเดิม)
- ตัวเลขรวมต้องเท่ากับ "ติดตามแล้ว (ครั้ง)" รวมทุกแอดมินในตัวกรองเดียวกัน

## Non-goals

- ไม่เพิ่มแท็กใน Pancake ไม่แก้ฐานข้อมูล ไม่ดึงข้อมูลเพิ่ม (ใช้ `fu.events` ที่โหลดอยู่แล้ว)
- ไม่ใส่คำตัดสิน แสดงแค่ตัวเลข

## Approaches

- **ตารางในหน้ารายงานเดิม ← เลือก** ใช้ตัวกรองที่มีอยู่ ไม่มีเมนูใหม่
- แยกเป็นแท็บใหม่ — ต้องทำตัวกรองซ้ำ ไม่คุ้ม

## Calls ของผม

- ตรรกะใน `src/followup/report.ts` เป็นฟังก์ชัน `roundsByDay(...)` พร้อมเทสต์ · การ์ดอยู่ใน `Report.tsx` ใต้ตารางรายแอดมิน
- ช่องที่เป็น 0 แสดง "–" ให้อ่านง่าย
