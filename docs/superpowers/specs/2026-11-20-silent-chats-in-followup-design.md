# แชทเงียบใหม่ในแท็บติดตาม 7 รอบ — Design (short)

วันที่ 20 พ.ย. 2026 · ต่อจาก `2026-11-16-followup-auto-intake-design.md` · เจ้าของอนุมัติในแชท 20 พ.ย.

## Intent

แท็บ "ต้องตามวันนี้" บอกได้แค่ว่าแชทไหนเงียบ (ขั้น พร้อมสั่ง/ลังเล/ขอโปร/ขอราคา + ไม่เปิดอ่าน/อ่านไม่ตอบ จากไฟล์ล่าสุดของแต่ละเพจ)
แต่บันทึกไม่ได้ว่าตามแล้วหรือยัง และได้ผลอย่างไร แอดมินอยากรู้รายคนว่าตามหรือยัง GM อยากรู้ว่าตามกลับได้กี่คนจากกี่คน
เจ้าของตัดสินใจ: ใช้แท็บ "ติดตาม 7 รอบ" เป็นที่บันทึกที่เดียว ย้ายรายชื่อเข้าไปอยู่ในนั้น และเลิกเมนู "ต้องตามวันนี้"

ข้อมูล 20 พ.ย.: รายชื่อต้องตามวันนี้ 10 แชท ไม่มีแชทไหนอยู่ในคิว 7 รอบ (183 ราย) — สองรายการไม่ซ้ำกัน

## Goals

- ในแท็บติดตาม 7 รอบ มุมมอง "งานติดตามวันนี้": กล่องบนสุด "แชทเงียบใหม่ ยังไม่ได้ตาม (N)" = รายชื่อเดิมของต้องตามวันนี้ ตัดแชทที่อยู่ในคิวแล้ว (ผูกด้วย conversation_id) มีตัวกรองขั้น
- ปุ่ม "บันทึกผล" ต่อแชท → เลือกผล (ส่งข้อมูลแล้ว / รอลูกค้าตอบ / ซื้อแล้ว + เลขออเดอร์ / ขอหยุดติดต่อ) + หมายเหตุ → ลูกค้าเข้าคิว และผลนี้เป็นรอบถัดไปที่ยังเปิดอยู่
- ลบเมนู "ต้องตามวันนี้"; ปุ่มในหน้าสรุปพาไปแท็บติดตาม 7 รอบ
- รายงาน GM: "แชทเงียบใหม่: ขึ้นรายชื่อ Y คน · ตามแล้ว X · ซื้อ Z" ในช่วงเวลาและเพจที่เลือก

## Non-goals / anti-goals

- ไม่ดึงแชทเงียบเข้าคิวเองโดยไม่มีคนกด (เจ้าของต้องการให้แอดมินบันทึกผลจริง)
- ไม่เปลี่ยนกติกาของคิวเดิม (รอบตายตัว วันที่ 2/5/7/14/30/45/60, บันทึกตามลำดับ, ซื้อแล้ว/หยุดติดต่อปิดงาน) ตาม brief หน้า 8–9, 12
- ไม่แสดงชื่อ/เบอร์ลูกค้า

## Approaches

- **A (เลือก)** ผูกกับคิว 7 รอบ: ผลอยู่ที่เดียว รายงาน GM ใช้ต่อได้ ยืนยันด้วยเลขออเดอร์ และแท็กปิดทีหลังนับเป็นซื้อเองอยู่แล้ว ข้อแลก: ต้องเข้าสู่ระบบทีม และลูกค้าที่ยังไม่ซื้อจะมีรอบต่อไป
- B บันทึกแยกในหน้าต้องตามวันนี้: กดง่ายกว่า แต่ผลติดตามมีสองที่และรายงานต้องรวมสองแหล่ง
- C ใช้แท็กอย่างเดียว: ไม่ต้องกด แต่บันทึก "ไม่ตอบ" ไม่ได้และรู้ผลวันถัดไป

## Decided (owner)

- ที่บันทึกคือแท็บติดตาม 7 รอบ; เลิกเมนูต้องตามวันนี้; รายชื่อเห็นเฉพาะคนที่เข้าสู่ระบบทีม

## Builder's calls

- ฟังก์ชันใหม่ `fu_start_chat(actor, conversation_id, result, note, order)` ทำทุกอย่างในฐานข้อมูลครั้งเดียว: ล็อกเดียวกับ sync, สร้างลูกค้า (ชื่อ/สินค้า/เพจ/ลิงก์ ตามกติกา sync), source = `chat`, ประวัติ "เริ่มติดตามจากแชทเงียบ"
- วันที่ 1 = วันแรกที่แชทนี้อยู่ในไฟล์ข้อความ (brief: ยึดวันที่คุยครั้งแรก) แต่ไม่เก่ากว่าวันนี้ − 59 วัน เพื่อให้ยังเหลือรอบ 7
- รอบที่กำหนดก่อนวันนี้ข้ามอัตโนมัติ เหตุผล "เข้าระบบทีหลัง" (เหมือน sync) แล้วผลที่กดเป็นรอบถัดไป
- ผู้ดูแล = คนที่กดถ้าเป็นแอดมิน; ถ้า GM กด → ใช้กติกาเดียวกับ sync (แท็กชื่อแอดมินก่อน, ไม่มีก็คนงานน้อยกว่า)
- ถ้าแชทอยู่ในคิวแล้ว (กดซ้ำ / sync ดึงเข้าไปก่อน) → แจ้ง "แชทนี้อยู่ในคิวแล้ว กดโหลดใหม่"; แชทที่เคยลบออกจากคิวแล้วกลับมากดใหม่ได้
- รายงาน: Y = แชทที่เคยขึ้นรายชื่อแชทเงียบในวันใดก็ได้ของช่วงที่เลือก (คำนวณจากไฟล์ข้อความรายวัน); X = ในนั้นที่อยู่ในคิวและมีรอบที่บันทึกแล้วหรือมีสถานะ; Z = สถานะซื้อแล้ว ตัวกรองแอดมินใช้กับ X/Z
- ป้ายบนแถบซ้ายของแท็บติดตาม 7 รอบ = งานวันนี้+ค้าง + แชทเงียบที่ยังไม่ได้ตาม
